What these measurements can and cannot show
  • Bars are provider-reported input tokens, including cached input. Unknown usage is shown as unknown, never zero. Denied attempts were not dispatched.
  • Colored token categories are inferred from provider item IDs and structure. They sum to the reported input, but do not isolate the exact memory-projection payload. Unattributed providers show total input only.
  • The original experiment did not retain complete wire payloads. Its native-history counts are timestamp-based reconstructions; compaction calls can use a different summary context. Stored memory counts are not injected-message counts, and logged admission estimates are not measured tokens.
  • The final experiment captured item order, serialized item byte sizes, and pruning markers. It did not capture full raw payloads. The byte strip excludes separately supplied instructions/tool schemas and is not a token split.
  • Unchanged leading items are determined by comparing private item hashes between consecutive captured requests. This does not prove prompt-cache reuse. Reported cached input is the cache measurement.
  • A and B followed independent trajectories. Matching call numbers are not matching reasoning steps. Original and final experiments used different policies and cohorts.
  • Reasoning tokens are already included in output. A completed request, a passing checker, and a successfully completed task are distinct outcomes.
